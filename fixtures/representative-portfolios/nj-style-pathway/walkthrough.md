# NJ-style regulated pathway Portfolio walkthrough

This research-only fixture demonstrates a versioned regulated Profile, one student case, independent ELA and mathematics components, explicit pathway selections, supporting records, checklist findings, an attestation, a local approval, conditional readiness, a local review Snapshot, a school-level batch, a corrected resubmission, receipts, and a component-specific external outcome.

The fixture is not an NJDOE form or operational appeal. Restricted operational sources remain unresolved, so the Profile cannot be activated. The local evidence package is distinct from school-level batch files, and the corrected submission preserves the first submission and receipt.
