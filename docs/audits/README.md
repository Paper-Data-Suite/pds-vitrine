# Vitrine Audits

Audits evaluate whether Vitrine research, decisions, designs, examples, fixtures, and implementation claims remain mutually consistent. They preserve findings even after correction and distinguish foundation readiness from runtime implementation completeness.

## Current audits

- [Portfolio foundation audit](portfolio-foundation-audit.md) — skeptical closure review for the v0.1.0 foundation.
- [Portfolio foundation traceability](portfolio-foundation-traceability.md) — maps every foundation issue and exit condition to governing evidence.
- [Portfolio foundation findings](portfolio-foundation-findings.md) — append-preserving finding register with severity, disposition, resolution, and validation.
- [Machine-readable audit manifest](portfolio-foundation-audit.json) — validator input for baselines, ADR dispositions, findings, exit conditions, and verdict.
- [Issue #13 validation report](../validation/issue-13-portfolio-foundation-validation.md) — commands, automated checks, and final results.

## Authority

An audit records reviewed evidence and maintainer dispositions. It does not create legal compliance, activate an operational regulated Profile, or claim that runtime features exist when the repository contains only foundation contracts.
