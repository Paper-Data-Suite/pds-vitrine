## Privacy audit

### Repository and release evidence

The audited v0.3.0 validation/acceptance paths use synthetic identities and content.
Release documentation explicitly prohibits real student records, credentials, private
configuration, producer-native paths, or absolute workstation paths in public evidence.

**Disposition:** `CONFORMS`.

### Source-read authorization

`producer_reader_services.read_authorized_producer_manifest()` performs:

```text
authorize source read
-> verify exact Core Publication manifest path/digest
-> read immutable verified bytes
-> invoke exact installed public producer reader
```

Denied, unresolved, invalid, missing, and integrity-failed states use stable bounded
errors.

**Disposition:** `CONFORMS`.

### Producer Artifact authorization

Quillan and Concord copied-source providers use a separate deployment-owned Artifact
authorization decision after Vitrine/Core provenance revalidation. Holding Snapshot
build authority or a frozen source context does not authorize producer Artifact I/O.
The providers use public producer Artifact APIs rather than reconstructed native paths.

**Disposition:** `CONFORMS`.

### Candidate suppression and negative state

Candidate inbox visibility explicitly removes `suppressed` from queryable outcomes and
returns no row for suppressed current Evaluations. Ineligible and unresolved
Evaluation-only states remain reviewable without fabricating Candidates.

The #71 negative matrix additionally proves denied/unresolved source authorization
fails closed.

**Disposition:** `CONFORMS`.

### Audience/disclosure boundary

The Build and Export Current Portfolio menu states that:

```text
Audience Rule constrains content; it does not identify a recipient.
Acknowledging obligations does not authorize disclosure.
the output is a local directory Export.
the workflow does not deliver the Export.
Export creation is not disclosure permission or delivery.
```

v0.3.0 therefore stops before the ADR 0008 Recipient Scope, Disclosure Review,
Disclosure Authorization, redaction/de-identification, and Disclosure Event machinery.

**Disposition:** `CONFORMS — INTENTIONALLY LIMITED`.

### Diagnostic and attention privacy

Normal source-reader failures use stable error codes/messages rather than raw producer
exception strings. Candidate inbox and attention operate on bounded Vitrine projections.
The #71 scenario also refuses raw producer failure text.

**Disposition:** `CONFORMS`.

### Backup and suite boundary

The Core module-operations provider is a thin adapter to Vitrine-owned readiness and
attention logic. Suite integration does not read or reinterpret producer/Vitrine
private records directly, and class-scoped attention is withheld where Portfolio-wide
meaning cannot safely be assigned to one class.

**Disposition:** `CONFORMS — INTENTIONALLY LIMITED`.

## Provenance audit

### Exact source authority

Candidate discovery and Snapshot acquisition preserve exact Core Publication,
registration, manifest, producer projection, Candidate Evaluation, Candidate,
Selection, Placement, Composition, and Build Plan identities.

**Disposition:** `CONFORMS`.

### Currentness and no silent retargeting

The implementation uses explicit current pointers/series authority rather than newest
timestamp/maximum revision heuristics. #71 proves a real ScoreForm successor makes the
old Evaluation stale without retargeting and that Quillan source drift / Concord exact
source removal do not substitute alternate bytes.

**Disposition:** `CONFORMS`.

### Curation provenance

Selection, Placement, Arrangement, Annotation, Reflection, Review, and Composition
remain separate append-preserving record families. Candidate eligibility does not
silently become Selection. Replacement/withdrawal retain historical records.

**Disposition:** `CONFORMS`.

### Frozen build provenance

Current Portfolio execution revalidates the reviewed preparation fingerprint and exact
state revision before mutation. The immutable Plan remains tied to the reviewed
Composition and exact source endpoints.

**Disposition:** `CONFORMS`.

### Digest/custody layers

Core manifest digest, producer/source digest claims, acquired/copied Entry digests,
Snapshot Manifest/Seal inventory, and Export integrity remain distinct. #71 proves
Export tamper detection and producer-independent verification of sealed Vitrine
custody after all three producer source roots disappear.

**Disposition:** `CONFORMS`.

## Guided usability audit

### Starter policy and Portfolio setup

Improvement/Showcase purpose selection filters explicit Profile choices; it does not
install hidden policy. Create Portfolio for Student displays exact roster identity,
resulting current/proposed Subject links, existing Portfolios, purpose/Profile choice,
and delays mutation until final confirmation.

**Disposition:** `CONFORMS`.

### Candidate inbox and curation

Teachers can inspect positive/negative/stale/selected state without internal graph
traversal. Guided Candidate review plans consequential actions before execution and
keeps Selection, Placement, Annotation, Reflection, Review, replacement, and
withdrawal as distinct actions.

**Disposition:** `CONFORMS`.

### Working Composition

Preparation exposes ordered section state, unplaced Selections, Profile requirements,
Review state, audience policy, and source observations. A preparation fingerprint and
state-revision checks prevent silent re-preparation after review.

**Disposition:** `CONFORMS`.

### Build and Export Current Portfolio

The workflow separates prepare/review/confirm/execute, requires an exact Audience Rule
and explicit choice when multiple Audience Contexts or Snapshot Series match, explains
unresolved obligations, and uses a high-friction final confirmation before building.

It does not label the local Export as sharing or delivery.

**Disposition:** `CONFORMS — INTENTIONALLY LIMITED`.

### Attention and suite integration

Attention is observational and bounded; suite operations consume Vitrine-owned
readiness/attention projections rather than reimplementing portfolio policy.

**Disposition:** `CONFORMS — INTENTIONALLY LIMITED`.
