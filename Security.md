# Security and Student Data

Vitrine is pre-1.0 local-first educational software. It is not a hosted service,
a legal-compliance certification, or a production authorization system.

## Student data

Do not commit, publish, or attach real student names, identifiers, work, scores,
feedback, signatures, disability information, disciplinary information, or other
education records to this repository. Tests and examples must use synthetic data.

Vitrine v0.2 can discover Core-backed synthetic fixture Publications after
canonical verification, inspect only explicitly authorized producer-shaped
development projections, persist Portfolio/Candidate/curation state, and build
immutable local Snapshot Editions and directory Exports. These Vitrine-owned
fixtures are not live ScoreForm, Quillan, or Concord integrations.

Source-read, curation, and Snapshot-build authority remain explicit fail-closed
integration points. Vitrine v0.2 does not implement production institutional
authentication, recipient authorization, consent, redaction/de-identification,
delivery, public hosting, or external submission. Future integrations must preserve
the no-leakage and minimum-necessary boundaries in accepted Vitrine ADRs 0005 and
0008.

## Reporting concerns

Report suspected vulnerabilities privately to the repository maintainer. Do not
include real records, credentials, access tokens, local configuration files, or
absolute workstation paths in a public report.
